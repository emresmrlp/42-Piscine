# C Programming Foundations

A collection of C projects focused on core programming concepts, memory management, algorithms, and Unix fundamentals.

## About

Built during an intensive programming curriculum with a strong focus on problem solving and low-level programming in C.

## Topics

* **C Fundamentals** — Variables, functions, control flow, and basic algorithms.
* **Pointers & Memory** — Pointer arithmetic, memory allocation, and memory management.
* **Strings & Arrays** — String manipulation and array operations.
* **Algorithms** — Sorting, recursion, and problem-solving exercises.
* **Unix & Shell** — Command-line tools, shell scripting, and filesystem operations.
* **Git** — Version control and collaborative development fundamentals.

## Standard

Projects are implemented primarily in **C** using the Unix development environment.
